# 台灣大樂透（Taiwan Lotto 649）歷史數據分析工具

## 專案說明

本工具提供台灣大樂透歷史開獎號碼的統計分析功能，透過分析過去的開獎記錄，找出出現頻率最高的號碼，並根據統計結果組合出推薦的號碼組合。

### ⚠️ 重要聲明

- **本工具僅供統計分析與學術研究使用，不構成任何投注建議**
- 樂透開獎為獨立隨機事件，每期開獎機率完全相同
- 歷史統計頻率不代表未來出現機率
- 任何號碼組合的中獎機率在數學上都是相等的
- 請理性看待樂透，切勿沉迷

## 功能特色

1. **歷史數據收集**
   - 支援從台灣彩券官網爬取歷史開獎資料（需要調整API）
   - 支援從JSON檔案載入歷史數據
   - 提供模擬數據用於測試和演示

2. **統計分析**
   - 統計每個號碼（1-49）的出現頻率
   - 分析熱門號碼（出現次數最多的號碼）
   - 分析冷門號碼（出現次數最少的號碼）
   - 計算各號碼的出現率百分比

3. **智能組合生成**
   - 基於歷史頻率生成5組推薦號碼
   - 採用多種策略：
     - 純熱門號碼組合
     - 熱門+次熱門混合組合
     - 區間平衡組合（均勻分佈於1-16、17-33、34-49）
     - 奇偶平衡組合
     - 隨機熱門組合

4. **結果輸出**
   - 完整的頻率分析報告
   - 推薦號碼組合列表
   - 結果匯出為文字檔

## 安裝與使用

- Python 3.7 或以上版本
- pip (Python 套件管理工具)

1. **安裝相依套件**

```bash
cd taiwan_lotto649
pip install -r requirements.txt
```

2. **執行分析程式**

```bash
python lotto_analyzer.py
```

### 使用方式

#### 方式一：使用模擬數據（預設）

直接執行程式，會自動生成500期的模擬歷史數據進行分析：

```bash
python lotto_analyzer.py
```

#### 方式二：從JSON檔案載入真實數據

如果你有準備好的歷史數據JSON檔案，修改 `lotto_analyzer.py` 中的 `main()` 函數：

```python
def main():
    analyzer = TaiwanLotto649Analyzer()
    
    # 從檔案載入
    analyzer.load_from_file('historical_data.json')
    
    # ... 其他程式碼
```

JSON檔案格式範例：

```json
[
  {
    "draw_number": 1,
    "date": "2024-01-01",
    "numbers": [3, 12, 23, 31, 38, 45],
    "special": 7
  },
  {
    "draw_number": 2,
    "date": "2024-01-04",
    "numbers": [5, 15, 22, 28, 35, 42],
    "special": 11
  }
]
```

#### 方式三：從官網爬取數據

要從台灣彩券官網爬取真實數據，需要：

1. 分析台灣彩券官網的API結構
2. 修改 `_fetch_from_official_api()` 方法
3. 實作HTML解析邏輯

由於官網結構可能變動，建議先查看官網的實際API再進行調整。

### 主要類別

#### `TaiwanLotto649Analyzer`

樂透分析器主類別，提供以下方法：

- `fetch_historical_data(max_draws)`: 獲取歷史開獎資料
- `load_from_file(filepath)`: 從JSON檔案載入數據
- `save_to_file(filepath)`: 儲存數據到JSON檔案
- `analyze_frequency()`: 分析號碼出現頻率
- `get_top_numbers(top_n)`: 取得最熱門的前N個號碼
- `generate_recommended_combinations(num_combinations)`: 生成推薦號碼組合
- `print_frequency_report()`: 列印頻率分析報告
- `print_recommendations(combinations)`: 列印推薦組合
- `export_results(output_file)`: 匯出結果到檔案

## 技術細節

### 數據來源

1. **官方來源**
   - 台灣彩券官方網站: https://www.taiwanlottery.com.tw
   - 提供完整的歷史開獎資料查詢

2. **替代方案**
   - 使用公開的CSV/JSON資料集
   - 自行建立數據庫收集歷史數據

### 分析方法

1. **頻率統計**
   - 使用 Python `collections.Counter` 進行計數
   - 統計每個號碼在所有歷史開獎中的出現次數
   - 計算出現率 = (出現次數 / 總期數) × 100%

2. **組合策略**
   - 熱門策略：選擇出現頻率最高的號碼
   - 平衡策略：考慮號碼分佈的均勻性
   - 混合策略：結合熱門與次熱門號碼

### 數學基礎

台灣大樂透的中獎機率（頭獎）計算：

```
C(49, 6) = 49! / (6! × 43!) = 13,983,816

中獎機率 = 1 / 13,983,816 ≈ 0.000007151%
```

**重要提醒**：無論選擇什麼號碼組合，中獎機率都是相同的。歷史頻率分析不會改變數學機率。

## 常見問題

### Q1: 歷史熱門號碼是否更容易中獎？

**A**: 不會。每期樂透開獎都是獨立事件，每個號碼被抽中的機率都是相等的（1/49）。歷史頻率只是統計結果，不代表未來機率。

### Q2: 為什麼要做這個分析？

**A**: 主要用於：
- 統計學習和實踐
- 數據分析技能訓練
- 了解機率與統計的概念
- 僅供娛樂和研究參考

### Q3: 能否保證中獎？

**A**: **絕對不能**。這是統計分析工具，不是預測工具。樂透是隨機遊戲，無法預測。

### Q4: 如何取得真實的歷史數據？

**A**: 可以：
1. 從台灣彩券官網手動下載
2. 撰寫爬蟲程式自動抓取
3. 使用公開的數據集
4. 聯繫相關單位申請數據
